# M0 — 專案地基

> 前置：無。這是第一步。
> 目標：把可以開發的 Next.js 骨架＋design system＋主題切換建起來，之後每個 milestone 都長在這上面。

## 目標 (Goal)
建立 Next.js 16 專案，導入 design tokens、字型、light/dark 主題切換、base UI 元件，以及空的 layout 骨架。

## 範圍 (In Scope)
- `create-next-app`：App Router + TypeScript + Tailwind v4。
- `app/globals.css`：貼入 `docs/design-tokens.md` 全部 CSS variables（Primitives / Semantic light+dark / Scale / DataViz）。
- `next/font`：Noto Sans TC（中文）+ Inter（數字/英文），self-host。
- `<ThemeProvider>`：切換 `data-theme`，寫入 localStorage，`<head>` inline script 提前套用防閃爍。
- shadcn/ui base 元件並套上 token：`Button`（primary/accent/secondary 三變體）、`Card`、`Dialog`、`Tabs`、`Badge`。
- `app/layout.tsx`：`<html lang="zh-Hant">` + `<Nav>` + `{children}` + `<Footer>` 骨架（Nav/Footer 內容先放假的，M1 才做真的）。
- 一個 `/` 首頁暫時放「Hello + 主題切換鈕」測試用。

## 不做 (Out of Scope)
- 真正的 Nav/Footer 內容（M1）。
- 任何頁面內容、地圖、資料抓取。

## 限制 (Constraints)
- 顏色/間距一律用 token，不寫死。
- Button 等 base 元件用 `class-variance-authority` 管變體。
- 不裝任何地圖/3D/圖表相關套件。

## 完成定義 (Definition of Done)
- [ ] `npm run build` 成功、`npm run dev` 起得來。
- [ ] 首頁有主題切換鈕，切換時背景/文字色變化正確、**重整不閃爍**。
- [ ] Button 三變體顏色符合 token（primary=紅、accent=藍、secondary=描邊）。
- [ ] `data-theme="dark"` 時所有 semantic 色正確反轉。
- [ ] TypeScript strict 無錯誤、無 lint 錯誤。

## 驗證指令 (Verify)
```bash
npm run build                 # 應無錯誤
npm run dev                   # 開 localhost:3000
# 瀏覽器：點主題切換鈕→確認變色→重整→確認不閃爍
npx tsc --noEmit              # 型別檢查應乾淨
# 用 Lighthouse (Chrome DevTools) 測首頁 mobile，Performance 應接近 100
```

## 完成後
1. 貼出 `npm run build` 與 `tsc --noEmit` 的輸出。
2. 截圖 light 與 dark 兩種主題的首頁。
3. 更新 `docs/progress.md`：M0 → 🔵 待驗收。
4. **停下來，等人類說「M0 通過，開始 M1」。**
