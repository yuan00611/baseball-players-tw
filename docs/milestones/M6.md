# M6 — 打磨 + 進階（MVP 後）

> 前置：M1–M5 已驗收通過，MVP 已上線。
> 目標：加上加值功能，但每項仍是獨立小 milestone，逐個做逐個驗收。

## 可選項目（每個都獨立提計畫、獨立驗收，不要一次全做）
1. **開場動畫**（Three.js/r3f）：首次進站播放、`sessionStorage` 記錄、`next/dynamic ssr:false`、手機降級 2D/影片、`prefers-reduced-motion`。
2. **資料視覺化**：打擊率折線、噴球熱區圖（用 DataViz token + D3/visx，SVG 可 SSR）。放球員頁數據區。
3. **電子報**：Footer 訂閱框接後端（如 Resend / Buttondown）。
4. **贊助 CMS 化**：把 M1 寫死的贊助商改由 Sanity/Payload 管理（層級、連結、有效期）。
5. **Mapbox 升級**（可選）：需要街道級縮放/上千點聚合時，把 teams 經緯度餵給 react-map-gl；手機維持 SVG 版。
6. **遊戲模式皮膚**（彩蛋）：主地圖右上「🎮 遊戲模式」切換，同資料換像素/皮克敏渲染。

## 限制 (Constraints)
- 每個進階功能都必須維持既有效能預算（重的東西 lazy + 降級）。
- 不可為了炫技犧牲 SEO：內容層永遠是 HTML。

## 完成後
每完成一項，更新 `docs/progress.md` 並停下驗收，再進下一項。
