# M2 — 精準美國地圖（靜態）⭐

> 前置：M1 已驗收通過。
> 目標：做出**地理精準**的美國地圖，球團 pin 與州界完全對齊。這是全站核心，務必精準。

## 目標 (Goal)
`<UsMap>` 元件：官方州界 SVG + 真實球團經緯度 pin，純靜態、SSR、手機輕量。

## 範圍 (In Scope)
- 裝套件：`react-simple-maps` `d3-geo` `topojson-client` `us-atlas`。
- `data/teams.ts`：30 支 MLB 球團 + 相關小聯盟球場，含 `{ id, name, city, latLng:[lng,lat], level }`（經緯度用真實值）。
- `data/players.ts`：台灣選手 ↔ 所屬球團對應（先放已知的幾位）。
- `components/map/UsMap.tsx`：
  - 用 `geoAlbersUsa()` 投影 + `us-atlas/states-10m.json`。
  - 有台灣選手的球團 pin 用 `--brand-primary` highlight，其餘球場用 `--brand-accent` 小點。
  - pin 座標用**同一個 projection** 從 latLng 換算，確保對齊州界。
- 桌機正常尺寸；手機用 `viewBox` 等比縮放（`preserveAspectRatio`）。
- 地圖是 Server Component 直出 SVG（靜態不需互動時盡量 SSR）。

## 不做 (Out of Scope)
- tab 切換、hover 卡、即時賽程（M3）。
- 台灣/日本地圖（之後）。
- **絕不用 Mapbox / WebGL。**

## 限制 (Constraints)
- `states-10m.json` 放 `public/` 或用套件 import，一次載入。
- 州界資料來源必須是 `us-atlas`（US Census Bureau），不可手繪。
- 顏色用 token。

## 完成定義 (Definition of Done)
- [ ] 州界精準：抽查 5 州（加州、德州、佛州、紐約、華盛頓州）輪廓對比 Google Maps 無明顯偏差。
- [ ] 球團 pin 落在正確城市：抽查波士頓(Fenway)、洛杉磯(Dodger)、西雅圖(T-Mobile) 位置正確。
- [ ] `view-source` / `curl` 看得到 `<svg>` 內容（SSR 成功，非 client-only）。
- [ ] 手機不破版、無 WebGL、地圖相關傳輸 < 150KB gzipped。
- [ ] 阿拉斯加/夏威夷有正確出現（geoAlbersUsa 會擺左下）。

## 驗證指令 (Verify)
```bash
npm run build && npm run dev
curl -s localhost:3000/map | grep -c '<path'          # 應有大量 path（州界），>0
curl -s localhost:3000/map | grep -o 'geoAlbers\|<svg'  # 確認 svg 存在
# DevTools Network：篩 states-10m，確認大小 < 150KB gzipped
# 目視：對照 Google Maps 抽查 5 州輪廓 + 3 個球場 pin
```
