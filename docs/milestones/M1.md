# M1 — Navigation + Footer + 靜態關於頁

> 前置：M0 已驗收通過。
> 目標：把全站共用的導覽列、頁尾做完，並用最單純的「關於頁」驗證 RWD／主題／SEO／路由全通。

## 目標 (Goal)
完整可用的 Nav（桌機＋手機漢堡）與 Footer，加上 `/about` 靜態頁（團隊＋贊助，資料先寫死）。

## 範圍 (In Scope)
- `components/nav/Nav.tsx`：
  - 桌機 `sticky top-0` 高 64px。左 LOGO（棒球圖示＋「旅美幫」），右導覽 `地圖·選手·媒體牆·關於`＋主題切換鈕。
  - 手機 <768px：LOGO＋漢堡，點開 Radix Dialog 全屏選單。
  - 目前頁 `aria-current="page"`，色用 `--brand-accent`。
- `components/footer/Footer.tsx`：三欄（手機堆疊）品牌／網站地圖／社群＋電子報框。社群連到 mlbtwnet 四帳號（真 `<a>`）。
- `app/about/page.tsx`：hero＋團隊成員（6 人，資料在 `data/team.ts`）＋贊助分層（冠名／金級／好朋友，`data/sponsors.ts`）＋三顆 CTA。
- `Organization` JSON-LD（含 `sameAs` 四社群、`logo`）。
- LOGO 做成 `components/brand/Logo.tsx`（棒球 SVG＋字樣，綁 token，之後好換）。

## 不做 (Out of Scope)
- 地圖、選手頁、媒體牆、任何外部資料。
- 贊助商 CMS 化（先寫死，M6 再接 CMS）。

## 限制 (Constraints)
- Nav/Footer 的互動（漢堡、主題鈕）才 `"use client"`，其餘 Server Component。
- 社群連結：YouTube `@MLBTWNet`、IG/Threads/FB `mlbtwnet`。

## 完成定義 (Definition of Done)
- [ ] 手機漢堡選單開合正常，鍵盤可操作、focus trap、Esc 關閉（Radix 已內建，需驗證）。
- [ ] 桌機/手機 Footer 佈局符合 Figma。
- [ ] `/about` 有正確 `<title>`／OG／`Organization` JSON-LD。
- [ ] 四社群連結正確導向。
- [ ] 320–430px 無破版；`md` 斷點導覽列正確切換。
- [ ] 導覽列跳轉各路由正常（雖然其他頁還是空的）。

## 驗證指令 (Verify)
```bash
npm run build && npm run dev
curl -s localhost:3000/about | grep -o '<h1[^>]*>[^<]*</h1>'      # 應有唯一 h1
curl -s localhost:3000/about | grep -o 'application/ld+json'        # 應有 JSON-LD
# 手機模擬（DevTools 375px）：開漢堡→Esc 關→Tab 走訪選單
# 貼 /about 的 JSON-LD 到 Google Rich Results Test 應通過 Organization
```
